# Task 1:  Landing Page

A visually polished, responsive static landing page built to demonstrate foundational HTML5 and CSS3 layout skills. 

## Project Objective
The goal of this project is to build a clean, well-structured landing page for a product, service, or brand from scratch using semantic HTML and custom CSS. 

## Tech Stack
* **HTML5:** For semantic web structure.
* **CSS3:** For styling, layouts, and responsiveness (No JavaScript used).

## Features implemented
* **Sticky Navigation:** A fixed/sticky navbar containing at least 3 navigation links for smooth user orientation.
* **Hero Section:** An engaging introductory section featuring a prominent headline, subheadline, and an clear Call-to-Action (CTA) button.
* **Content Sections:** At least two distinct sections (such as Features, About, or Testimonials) to showcase product/service details.
* **Footer Area:** A clean footer component with placeholder social media and contact links.
* **Responsive Design:** A fully adaptive layout optimized for mobile, tablet, and desktop viewports using CSS Flexbox or Grid.
* **Intentional Box Modeling:** Zero element overlap achieved by explicitly configuring margins, padding, and `box-sizing: border-box`.
* **Clean Typography:** Professional font pairing with distinctive sizing hierarchies separating headings from body copy.
* **Consistent Palette:** A unified color scheme applied seamlessly across all sections of the page.

## Getting Started

### Prerequisites
You only need a modern web browser (like Chrome, Firefox, Edge, or Safari) to run this project.

### Installation & Running Local
1. Clone or download this repository to your local machine.
2. Navigate to the project folder.
3. Open the `index.html` file directly in any web browser to view the page.

```text
├── index.html       # Main HTML structure of the landing page
└── style.css        # Custom CSS styles, layout rules, and media queries
```
