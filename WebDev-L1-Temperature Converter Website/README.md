# Task 3: Temperature Converter Website

An interactive web-based utility tool built to perform real-time temperature conversions between Celsius, Fahrenheit, and Kelvin scales with robust input validation.

## Project Objective
The objective of this project is to build a functional, user-friendly temperature converter from scratch using semantic HTML, custom styling, and vanilla JavaScript for dynamic computation and error handling.

## Tech Stack
* **HTML5:** For creating structural forms and layout controls.
* **CSS3:** For a clean, centered interface and interactive states.
* **JavaScript (Vanilla):** For mathematical conversion logic and real-time input validation.

## Features Implemented
* **Numeric Input Validation:** An input field that validates data in real-time, rejecting non-numeric values and showing user-friendly error messages.
* **Unit Selection:** Flexible choices using dynamic dropdown menus or radio buttons to pick the input temperature scale (Celsius, Fahrenheit, or Kelvin).
* **Auto-Conversion / Dual Display:** Instantly converts and outputs results into all remaining temperature units simultaneously.
* **Trigger Mechanism:** A manual "Convert" button that triggers precise mathematical calculations on click.
* **Result Display Area:** A dedicated output region showcasing beautifully formatted conversion output with correct unit symbols (°C, °F, K).
* **Edge Case Handling:** Validates physical limits and presents clear alerts for absolute zero violations (e.g., values less than -273.15°C).
* **Centered UI Layout:** A clean, visually balanced, and fully centered interface with precise form labeling.

## Getting Started

### Prerequisites
A modern web browser (such as Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari) is required.

### Running the Project Locally
1. Download or clone this project repository.
2. Locate the project folder on your system.
3. Open `index.html` inside any web browser to test the tool.
