# Task 2: Personal Portfolio

A professional personal portfolio website designed to showcase skills, projects, and contact information, acting as a comprehensive digital résumé.

## Project Objective
The objective of this project is to create a clean, responsive, and visually appealing personal portfolio from scratch using semantic HTML, custom CSS, and JavaScript to establish a professional online presence.

## Tech Stack
* **HTML5:** For semantic content structuring.
* **CSS3:** For styling, layouts, consistent branding, and responsiveness.
* **JavaScript:** Used for interactive enhancements, smooth animations, and dynamic behavior.

## Features Implemented
* **Profile / Hero Section:** Features the developer's name, professional role title, and a high-quality professional photo (`profile.png`).
* **About Me Section:** A brief summary (2-3 sentences) detailing educational background, core technical interests, and career objectives.
* **Skills Section:** A structured visual grid or clean list layout displaying core technical skills and tools.
* **Projects Section:** Includes at least two interactive project showcase cards complete with titles, short descriptions, and placeholder links to GitHub repositories.
* **Contact Section:** A dedicated area providing essential contact details including name, email address, and quick links/icons for LinkedIn and GitHub profiles.
* **Smooth Scroll Navigation:** Features an intuitive navigation bar enabling seamless scrolling between the different sections of the page.
* **Consistent Branding:** Built using a uniform color palette and a clean typography hierarchy across the entire site.
* **Fully Responsive Design:** Optimized using modern responsive layouts to ensure usability across both mobile viewports and desktop monitors.

## Getting Started

### Prerequisites
You only need a modern web browser (such as Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari) to view and test this website.

### Running the Project Locally
1. Clone or download this project repository to your local directory.
2. Open the project root folder.
3. Double-click the `index.html` file to launch the live portfolio site instantly in your default web browser.
